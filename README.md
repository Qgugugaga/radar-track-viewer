# 雷达航迹可视化

基于 Vue 3 + Vite + Canvas 的纯前端雷达航迹展示页面，无后端服务器，数据全部在前端解析处理。

## 运行

三种方式任选（端口固定为 **5180**）：

```bash
# 方式一：双击 start.bat（或 start.ps1），一键后台启动并打印访问地址
# 方式二：VS Code 终端（务必先打开本目录 radar-viewer）
npm install
npm run dev
# 方式三：命令行
powershell -NoProfile -ExecutionPolicy Bypass -File start.ps1
```

停止：运行 `stop.ps1`（或 `powershell -File stop.ps1`）。

访问地址：http://127.0.0.1:5180/ 或 http://localhost:5180/（局域网设备可用 `start.ps1` 打印的 Network 地址）。

## 数据

`public/track-data.csv`（UTF-8），由工作区根目录《架次一-雷达1航迹0719(调整格式后).csv》转码而来。
页面在浏览器中直接 fetch 并解析，仅取用「经度、纬度」两列（点时间仅作悬浮提示展示）。

## 交互

- **鼠标滚轮**：以光标为中心缩放（改变比例尺与点的大小），无固定中心点
- **按住左键拖空白处**：平移画面，浏览比例变化后视野外的点
- **按住圆点拖动**：调整该点的经纬度，其余点保持自身坐标不动，航迹连线实时随之变化
- **恢复坐标**：一键把所有点恢复到初始经纬度（保持当前缩放/平移）
- **恢复视野**：一键让外接矩形恰好完整展现在页面中
- **显示航迹连线**：开关
- **缩放范围**：最小 0.5×、最大 50× 初始适配比例（改 `src/App.vue` 中 `sMax` 一行的 `50` 即可调整）
- **平移范围**：限制在数据外接矩形附近（各边 25% 余量），放大后也不会把数据拖出视野太远

坐标系：直角坐标，原点在左下角，X 轴 = 经度（页面下方固定），Y 轴 = 纬度（页面左方固定），
缩放只改变轴比例与点的大小，轴线位置始终不动。
